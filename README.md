# Sublime Refrigeração — V3 totalmente local

Versão local-first para Android/PWA. Não usa Supabase.

Recursos:
- clientes
- ordens de serviço
- fotos antes/depois usando câmera/galeria
- próxima manutenção preventiva
- mensagem pronta via WhatsApp
- backup/restauração JSON com fotos em base64
- IndexedDB no aparelho
- PWA/offline para a interface

Importante:
- Os dados ficam neste navegador/aparelho.
- WhatsApp precisa de internet para enviar.
- Faça backups regularmente.
- Esta V3 não sincroniza entre celulares.

Instalação:
1. Publique estes arquivos em um endereço HTTPS (por exemplo GitHub Pages).
2. No Android, abra no Chrome.
3. Menu ⋮ -> Adicionar à tela inicial/Instalar app.

Para o uso mais seguro, manter o backup em Google Drive/armazenamento externo.
